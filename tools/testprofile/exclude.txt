# Settings that tools/testprofile/coverage.sh does not require in profile.cfg or a variant. One line each:
#   Section|key (a glob: * matches anything)|reason
# A new feature-like setting goes into profile.cfg (or a variant) with a comment and a README line, NOT here. Only
# debug views, tuning values, bake parameters and settings that a preset or a default already switches on belong here,
# and the reason says which.

# --- debug views and diagnostics: they replace the picture or write files; switch one on by hand (README) ---
Rendering|gbuffer debug view|debug view: replaces the picture with a stored image
Rendering|*debug*|debug view: replaces the picture (wetness, cover, cloud shadows, sun glow, volumetrics, volumetric clouds, taa, ao temporal)
Rendering|lightning debug age|test aid: holds one flash at a chosen age
Rendering|gi debug|debug: draws the light probes as octahedra
Game|creativemotion animation compare|developer comparison of two animation paths, logs bone differences
Game|creativemotion animation debug|developer trace: about 1500 log lines a second per actor
Shadows|enable debug hud|debug: shows the shadow maps
Shadows|enable debug overlay|inherited debug overlay; not read by the VSG renderer

# --- bake parameters: they only change what `openmw --bake-gi` and friends write; prepare.sh uses the defaults ---
Rendering|gi bake *|bake parameter of the light probe and sky visibility bakers
Cells|incremental build budget ms|tuning of incremental cell build (default 3 ms)
