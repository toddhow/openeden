# Task: Morrowind moons setting
Design doc section: `docs/tasks/0127-skyrim-weather-source.md`, stage W-S4 (moons); `apps/openmw/mwrender/CLAUDE.md`, "The moons".
Goal: a setting, off by default, that makes Morrowind's Masser and Secunda visible on the night sky (toddhow, 2026-11-14: "We can make the moons visible as a setting").
Inherited code touched: `apps/openmw/mwworld/weather.cpp` (`WeatherManager::update`, the line that sets `mResult.mLitMoons`), `apps/openmw/mwworld/neutralweather.hpp` (new `moonsAreLit`), `components/settings/categories/rendering.hpp`, `files/settings-default.cfg`; the render side (`MWRender::Moon::setState(state, lit)`, `Sky::setMasserState`, `apps/openmw/mwrender/weather.cpp`) is unchanged.
Inputs / outputs: new `[Rendering] lit moons` (bool, default false). `WeatherResult::mLitMoons = moonsAreLit(gamePackWeather, setting)`.
Constraints: off by default; off must leave Morrowind frames byte-identical; the Skyrim path (`mRegionProvider != nullptr`) is unchanged. The moon's colour is `Moon::mColour` (1,1,1 until the console/script colour `Moons_Script_Color` is set on Secunda by `Sky::setMoonColour`), times the shadow blend; the pictures themselves (`tx_masser_*.dds`, `tx_secunda_*.dds`) carry red and grey. Morrowind's moon timing rules (fade angles, `Moons_*` fallback values) are read by `MWWorld::MoonModel` from `Fallback::Map` and are used as they are.
Acceptance criteria:
- [x] `moonsAreLit(false, false)` false, `(false, true)` true, `(true, x)` true (3 tests in `testneutralweather.cpp`).
- [x] With the setting on, the moons show on a Morrowind night frame; viewed (Masser, dim red).
- [x] With the setting off, the fixed Balmora frame equals the recorded hash (and the setting on, by day, too); the night frame is identical in the sky to a parent build (terrain pixels at the bottom differ by run noise and the older parent tree).
Out of scope: Skyrim's own moon pictures, moon shadows on the ground, the aurora.
