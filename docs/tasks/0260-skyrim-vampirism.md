# Task 0260: Skyrim vampirism, first slice

Design doc section: `docs/design/game-packs.md`, diseases (task 0240), the stones' list of active spells (task 0237), effect conditions (tasks 0236 and 0238), ability numbers (task 0241), the Papyrus host (tasks 0176, 0181, 0198)
Goal: Sanguinare Vampiris, not cured within three game days, makes the player a vampire (stage 1) with the game's own message; the stages rise by game days without feeding and a feeding on a sleeper resets to stage 1; each stage's abilities, sunlight damage and powers work through the paths that exist; the state is saved.
Inherited code touched: none (all in `game_packs/skyrimse`, one SDK-free glue point in `neutral_world.*`, `files/`-free; tools and tests); at commit `0dedbf2735`.
Constraints: behind `[extension.skyrimse] vampirism` (default false, declared in `extension.json`; needs `papyrus`, which brings the stones path; `diseases` for the infection, `rest` for the game clock that waiting and sleeping move, `[Game] neutral combat` for the numbers); test aid `vampirism test stage = 1..4`. Off means unchanged: with the setting off nothing is created, the host additions are unused, and the Papyrus quest script is attached as it was.

Status: built on Windows. Written by one hand (tests first for the pure rules and the host additions, run red against stubs; the glue after), no fresh reviewer, no Linux gate.

## 1. Survey (the five masters; throw-away Python readers in `I:\Projects\OpenEden-work\combatai\vamp`, the scripts' source from the Creation Kit's `Scripts.zip` that ships in the game's Data folder)

- **The infection.** SPEL `DiseaseSanguinareVampiris` 0x0B8780 (SPIT type 1, a disease, task 0240): one effect `DisDamageHealthVampire` (Peak on Health, magnitude 25, two conditions on the MGEF: GetRandomPercent <= 10, GetIsID == 7). Its effect script `VampireDiseaseEffectScript` (decompiled source): `OnEffectStart` for the player registers `RegisterForUpdateGameTime(1)` and sets `VampireChangeTimer = GameDaysPassed.Value + 3`; every game hour it shows a message at hour 5 and at hour 19 (the sunrise and sunset messages) and, when `GameDaysPassed >= VampireChangeTimer`, `RegisterForSingleUpdate(10)`; `OnUpdate` calls `PlayerVampireQuest.VampireChange(player)` when the player is not in combat and his controls work, else retries in 10 seconds. So the turn is **three game days** after the infection.
- **The state is a quest.** QUST `PlayerVampireQuest` 0x0EAFD5 (start game enabled, VMAD with `QF_PlayerVampireQuest_000EAFD5` and `PlayerVampireQuestScript`, whose properties are filled by the record: the stage spells, the races, the messages, the GLOBs). `PlayerVampireQuestScript` (decompiled): `VampireStatus` (0 not a vampire, 1 to 4), `LastFeedTime`, `FeedTimer`, `VampireChange(Actor)` (disables the controls, the transform effects, sets the vampire race, removes the other diseases, `VampireStatus = 1`, `VampireProgression(player, 1)`, `RegisterForUpdateGameTime(12)`, `PlayerIsVampire = 1`), `VampireProgression(Actor, stage)` (adds and removes the stage's spells), `VampireFeed()` (stage back to 1, `RegisterForUpdateGameTime(12)` again), `VampireCure(Actor)` (removes everything; called by the quest fragment `QF_PlayerVampireQuest_000EAFD5`), and `OnUpdateGameTime()`: `FeedTimer = GameDaysPassed.Value - LastFeedTime`; when the player is not in combat, his controls work and the transform effects are not running: `FeedTimer >= 1` at stage 1 gives stage 2, `>= 2` at stage 2 gives stage 3, `>= 3` at stage 3 gives stage 4 (the stage 4 message, the vampire faction and "attack on sight" of the crime factions: commented out in the source).
- **The feeding.** The perks `VampireFeedBeds`, `VampireFeedBeds01` and `VampireFeedBedrolls` (`PRKF_VampireFeedBeds_000CF02C` and kin): `DLC1VampireTurn.PlayerBitesMe(target)`, `Game.GetPlayer().StartVampireFeed(target)`, `PlayerVampireQuest.VampireFeed()`. The perk entry is an activation on a sleeping NPC (the perk's own condition lists the sleeping state; not decoded here).
- **The stage spells** (per `VampireProgression`; all VERIFIED on the data): `AbVampire01..04` 0x2E1C3, 0xED099, 0xED09D, 0xED09E (abilities: frost resistance 20, 30, 40, 50) and `AbVampire01b..04b` (0x10F1EB, 0x10F1EA, 0x10F1E9, 0x10F1E8: fire weakness 20, 30, 40, 50 percent, `AbWeaknessFireConstant` value 41 with a negative sign); `AbVampireSkills`, `AbVampireSkills02` (stage 1 only; value 24 magnitude 0: a status); `VampireSunDamage01..04` 0xC1E8B, 0xED09A, 0xED09B, 0xED09C (abilities: health, magicka and stamina regeneration rates (155 to 157, 100 or 75 percent), Peak on health, magicka and stamina of 15, 30, 45 and 60, and a magnitude 0 effect with the ISMD script); `VampireDrain01..04` (spells), `VampireRaiseThrall01..04` (power, type 2: Reanimate), `VampireCharm` (power, from stage 2: Calm), `VampireInvisibilityPC` (power, stage 4: Invisibility and Night Eye), `VampireCureDisease` (a spell). `VampireVampirism` 0x0ED0A8 (ability: disease resistance 100) is on the vampire races, not given by the script.
- **Sunlight is a condition list on the SPEL's effects** (not on the MGEF): per effect `GetInWorldspace(0x2EE41) == 0`, `GetGlobalValue(GameHour 0x38) <= 19`, `GetGlobalValue(GameHour) >= 5`, `IsInInterior == 0` (CTDA function 310, 74, 74, 300; all answered by the effect-condition evaluator of task 0238; 0x2EE41 is the Forgotten Vale's worldspace). So the damage is exactly: outdoors between 5 and 19 o'clock, anywhere but the Vale.
- **The cure.** The quest `VC01` (the Cure: `SF_VC01VampirismCureRitual_0005DBA7`, the ritual) ends with the stage that runs the quest fragment `QF_PlayerVampireQuest_000EAFD5` (`VampireCure`). The pack runs no part of that quest chain; `VampireCure` is NOT called by anything here, and a Cure Disease potion does not cure vampirism (the vanilla `VampireCureDisease` spell is for others).
- **Not read here:** the vampire race swap (`SetRace`; the player keeps his own race and look), the vampire faction and attack-on-sight, the feeding animation, the transformation image space and sounds, Vampire Lord (Dawnguard), `Survival_VampirismLycanthropy`.

## 2. Design

- **What the game's own scripts run** (the Papyrus host): `VampireChange`, `VampireProgression`, `VampireFeed` and `OnUpdateGameTime` of `PlayerVampireQuestScript`. Their `AddSpell` and `RemoveSpell` calls land in the host's spell list, which `StonesService::active()` already feeds to the combat as the player's extra abilities (task 0237) and to the P key's list of powers (task 0241). So the stage's frost resistance and fire weakness (the weakness through `abilityWeaknessPercent`, task 0241), the Vampire's Servant, Seduction and Embrace of Shadows powers and everything else the data lists arrive through existing paths.
- **What this task adds to the host** (additive, `papyrus_host.hpp`): `callFunctionWith(form, script, function, arguments)` (a call with the player and a stage), `sendEventTo(form, script, event)`, `setGlobalValue(global, value)` (GameDaysPassed), `setNumberVariable` (a test aid and the stage sync), and the natives `Game.IsMovementControlsEnabled` and `IsFightingControlsEnabled` (always true: the quest's update acts only while the controls work).
- **What is HAND-WRITTEN** (`vampirism.*`; nothing in the data or the scripts does it, because the game's engine kept these clocks): (1) the three game days of Sanguinare Vampiris (`Machine`, `kChangeDays`), (2) the quest's 12 hour `RegisterForUpdateGameTime` (`kTickDays`, an `OnUpdateGameTime` event sent to the quest every 12 game hours), (3) the clock behind `GameDaysPassed` (the pack sets the GLOB each frame from the rest script's game clock, else the host's own script time), (4) the sunlight test: the data's own condition lists are evaluated by the effect-condition evaluator with the hour from the clock and the place from the core; only the clock and the place are ours, (5) `VampireVampirism` (disease resistance 100) is added to the player's active spells while he is a vampire (the race ability, because the player keeps his race), (6) the save chunk, (7) the feeding activation (below), (8) removing Sanguinare Vampiris at the turn (the vanilla effect ends with the race swap that is not built).
- **Sunlight** (`filterAbilities`): the stones' persistent list is passed through `vampirism::filterAbilities(spells, vampire, sunlit)`: the four sun damage spells are present only while `sunlit` holds (re-evaluated every frame; the stones service notices the list change and the combat applies the numbers, so the Peak effects take the player's health, magicka and stamina maxima down by 15 to 60 and the regeneration rates by 75 to 100 percent: the current value moves with the maximum, which is the damage).
- **Feeding.** `SkyrimCellSource::prepareConversation` (the core calls it when the player activates an actor, before any conversation) asks a feed hook first: for a sleeping actor and a vampire player it calls `VampirismService::feed()` (`VampireFeed()`) and the conversation that follows is one line, "You sink your fangs into the sleeper's neck." (the box closes at Goodbye); the sleeper keeps sleeping. A non-vampire talks to a sleeper as before (it wakes).
- **Settings** (declared in `extension.json`): `vampirism` (bool), `vampirism test stage` (0 off, 1 to 4: turns the player at the first game update after the quest script exists, then sets `VampireStatus`, `LastFeedTime` (stage - 1 days ago) and runs `VampireProgression`).
- **Saves.** The chunk `vampirism` v1 (17 bytes: the vampire flag and the two timers). The host's own state (the spell list, `VampireStatus`, `LastFeedTime`) is the Papyrus chunk. A load does not look for the script's status until it has been seen once this session (it would read 0 before the host restores).

## 6. Not run, limits and decisions for toddhow

Not run: the Linux gate and GCC `-Werror` (traps checked by hand), clang-format 14, clang-tidy, the Lua integration tests, `openmw-tests`, a fresh review, mutation runs, the vampire powers on the `P` key (it needs `character creation`; no unit test or game run presses it), the cure, a vampire in combat when the turn is due (unit tested only), a second load of the same save.

Limits: the player keeps his race and look (`SetRace` is a tolerant no-op), no vampire faction or attack on sight, no feeding animation, no transformation image space or sound, feeding is no crime, Sanguinare Vampiris is only caught by `diseases test infect` (the data has no race attack naming it), stage 4's Vampire's Servant adds +1 to health regeneration (task 0241's rule counts a power's timed Fortify), VampireDrain and VampireCureDisease are given but there is no spell menu, `mChanging` has no timeout if the change script fails, and the 12-hour timer sends one `OnUpdateGameTime` per poll (not one per missed interval after a long wait).

Decisions: (1) a vampire activating ANY sleeper feeds (the real game uses a perk entry with a condition; "asleep" here is "cannot talk now"); (2) the clock is the rest script's game clock, else the host's script time; (3) `VampireVampirism` is given by hand while a vampire, because the race is not swapped; (4) Sanguinare Vampiris is removed quietly at the turn; (5) the feed intercept sits in `SkyrimCellSource::prepareConversation` (no engine or SDK change).
