## Design (and why not the corner scheme)

Morrowind's blend map texel holds the four layer indices of the texel's corners; the shader blends them bilinearly, so every vertex has ONE dominant texture. A Skyrim quadrant has a base and up to six alpha layers with per-vertex opacity; several are partly visible at one vertex. Quantising to one dominant layer a vertex would lose every partial blend and put the transitions on a 256 unit lattice (the Morrowind scheme at 16 texels a cell), so roads would be one or two texels wide. A finer corner map is impossible without changing the ground texture tiling, which the shader derives from the blend map's width (one repeat per texel).

So the blend map gets a second layout, told by its shape (not square), in the SAME texture and binding: k x k quadrant slots of s x s texels hold four weights per vertex (bilinear, never across slots), and k rows of k texels below them the four layer indices of each quadrant (`texelFetch`). Everything after the decoding is unchanged (it already works on `textures[4]` and `blendCoeffs[4]`), so normal maps, parallax, PBR, wetness, cover, fog and GI work as before. See `components/neutralterrain/splat.hpp`.

Rules (settled on data in task 0117 where stated):
- Quadrants 0 south-west, 1 south-east, 2 north-west, 3 north-east; VTXT position = row * 17 + column (settled).
- Draw order: ATXT layer number ascending, file order breaking ties (the layer number is the order the construction kit shows; RECALLED-VERIFY that the engine draws in that order; measured below how often file order differs).
- Blend: base, then each layer lerped over the result by its opacity: `w(base) = prod(1 - o)`, `w(i) = o_i * prod over later j (1 - o_j)`. RECALLED-VERIFY (standard painter's blend); judged by frames.
- A null or dangling layer texture is the default ground texture (`dirt02.dds`), as for the base (settled in 0117).
- More than four layers (base included) in one quadrant: the four with the largest peak weight are kept and the rest of their weight is shared in proportion (the layer histogram below says how often this happens).
