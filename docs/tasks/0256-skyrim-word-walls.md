# Task: Skyrim word walls (M-S7): walking up to a word wall teaches the word, through the shipped scripts
Design doc section: `docs/tasks/0205-skyrim-shouts.md` (the shouts this feeds), `docs/tasks/0176-skyrim-papyrus-wiring.md` (the Papyrus host this runs on).
Approval: coordinator's order (2026-11-16). Full loop in form (the same hand wrote tests and code; tests first, run red against stubs).
Goal: with `[extension.skyrimse] papyrus` and `shouts` (and `[Game] neutral combat` for the player's place and look), walking up to a real word wall and looking at its words runs Skyrim's own `WordWallTriggerScript`, which calls `Game.TeachWord`; the HUD says "Word of Power learned: Fus"; the word is saved in the `shouts` chunk and can then be unlocked with a dragon soul and shouted.
Inherited code touched: none. OpenEden code touched outside the new files: `papyrus_host.*` (trigger events, natives, the player view), `vmad.cpp` (`combineScripts`), `records.*` (XPRM), `world_view.*` (`ReferenceScripts`), `shouts_service.*` (an announcement, `unlockWithSoul`, a binding), `neutral_world.hpp` (one sink), `skyrimse_game_pack.cpp` (wiring, `formClass`), CMake lists.
Constraints: everything behind the existing `papyrus` and `shouts` settings; no new setting; no allocation per frame once built; main thread; no wall clock.
Out of scope: the word wall glow, the wall's own animations (`Dark1Wild` and the other `playAnimation` calls are no-ops), the image space modifier fades, the whisper sound, box triggers and the other primitives, a ray for line of sight, the shout menu, `Actor.IsInCombat`.

## Survey (at `92e809d11c`)
- **The shipped scripts** (decompiled from `Skyrim - Misc.bsa` with houseCARL's decompiler, read only): `WordWallTriggerScript` (the wall; `DLC1`, `DLC2` and `DBSanctuary` variants, `WordWallTrigger02Script` and `WordWallTriggerBleakFallsScript` are the same idea), `WordWallListenerQuestScript`. Flow: the player enters the trigger volume (`OnTriggerEnter`), `StartWordWall` registers an update; `OnUpdate` loops (`Utility.wait(0)`) while he is in the volume: `isLooking()` is `Game.GetPlayer().HasLOS(lookTarget) && !wordLearned`; `StartFX` checks the distance to the look target (`< innerRadius` 300 and not `IsInCombat`, or `<= 200`): then `Game.TeachWord(myWord)`, `shoutGlobal.value = shoutGlobal.value + 1`, quest stage `myQuest`/`myStage`, enable `myEnabler`, disable the location marker and poke the listener quests; the farther bands (700, 1200, 2000) only play image space modifiers and wall animations.
- **The data** (a Python scan of the three official masters): 56 REFR carry a `WordWall*TriggerScript` (50 Skyrim.esm walls on the base ACTI `WordWallTrigger` 0x5095E, Bleak Falls Barrow, Shearpoint, Dawnguard and Dragonborn walls with `DLC1WordWallTriggerScript` and `DLC2WordWallTriggerScript`). Each trigger is a REFR with **XPRM** (32 bytes: three floats of bounds, three of colour, one float, a u32 type): **type 2 (sphere) in all 56, equal bounds, 2064.8 in 50 of them (1000 to 3994 in the rest)**. The reference VMAD names the words (`myWord01..03`, WOOP), `shoutGlobal` (a GLOB such as `WWUnrelentingForce`), the text refs, the look-target markers (REFR, with positions), the whisper and word sounds and optionally `myQuest`/`myStage`/`myEnabler`; the **base ACTI's VMAD carries the same script with the other properties** (`IMODLoop02/03`, `wordIMODWordLearned`, the two listener quests). Bleak Falls Barrow (`BleakFallsBarrow02`, trigger 0x709d2): word WordFus of `WWUnrelentingForce`, quest MS13 stage 60, look target at (-7875.7, 188.1, 651.7).
- **What the pack lacked:** (1) no trigger volumes (nothing sent `OnTriggerEnter` or `OnTriggerLeave`); (2) XPRM was not read; (3) a script both a reference and its base carry kept only the reference's properties (`combineScripts`), so the image space modifiers and listener quests were missing; (4) `Actor.HasLOS`, `ImageSpaceModifier.ApplyCrossFade` and the static `RemoveCrossFade` were not natives; (5) the player's position was unknown to the host (`GetDistance` of the player answered 0); (6) a WOOP and a GLOB had no Papyrus class; (7) learning a word said nothing; (8) no way to spend a soul in a session without the start-up test settings.

## What was built
- `triggers.*`: `TriggerVolume` (sphere only), `volumeContains`, `TriggerTracker` (enter and leave edges, an interior volume counts only in its own interior cell and an exterior one only outdoors, a deterministic order, 8,192 volumes at most), and `inViewCone` (the HasLOS approximation).
- `records`: `PlacedRef::mPrimitive` from XPRM (VERIFIED size 32; another size is counted odd). `world_view`: `ReferenceScripts` carries the primitive, position and cell.
- `vmad::combineScripts`: a script both carry gets the base's properties the reference does not set (the reference's values win; names compared without case).
- `PapyrusHost`: `addTrigger`, `setPlayerView`, `updateTriggers` (sends `OnTriggerEnter` and `OnTriggerLeave` with the player to the scripts on the volume's reference, run by the next tick), `resetTriggers` (a load); `Actor.HasLOS` (the view cone from the player's eye 120 units above his feet, half angle 45 degrees: OURS), `ImageSpaceModifier.ApplyCrossFade` and static `RemoveCrossFade` (no-ops), the player's position for `GetDistance`.
- The pack: the combat update reports the player's position, heading and pitch (`SkyrimCellSource::setPlayerStateSink`; so triggers need `[Game] neutral combat`), the driver registers the volumes of every built cell and updates them before the scripts run; `formClass` answers `WordOfPower` for a WOOP and `GlobalVariable` for a GLOB.
- `ShoutService`: `teachWord` announces "Word of Power learned: Fus" (the wording is ours) through the notices the shout HUD script already shows; `unlockWithSoul(editorId)` and the Mutate binding `skyrimse.shouts.unlock_word(name)` spend a dragon soul on a learned word (no shout menu exists, so a script plays the menu).
- `tools/wordwall_check`: the in-game scenario.
