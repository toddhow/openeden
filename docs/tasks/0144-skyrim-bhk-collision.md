# Task: Skyrim SE collision from the NIF's `bhk` shapes
Design doc section: `docs/design/skyrim-se-implementation-plan.md` section 4.9 (option B, with option A as the fallback)
Goal: with `[Game] neutral havok collision` on, a Skyrim SE model's collision is built from its own `bhkCollisionObject` -> `bhkRigidBody(T)` -> shape tree instead of from its visual triangles; a model with no usable `bhk` data keeps the visual-triangle collision.
Inherited code touched: `components/nifscene/{scene.hpp,build.hpp,build.cpp}` (an option and a field), `apps/openmw/mwphysics/skyrimshape.{hpp,cpp}` (the reader hook takes the setting), `apps/openmw/mwphysics/physicssystem.cpp` (passes the setting), `components/settings/categories/game.hpp`, `files/settings-default.cfg`, at commit `2a6bc83cb7`. The NIF record reader `components/nif/physics.*` is read, not changed.
Inputs / outputs: `Nif::NIFFile` records -> `NifScene::Havok::Collision` (plain shapes and bodies, `components/nifscene/havok.*`) -> `JPH::StaticCompoundShape` (`apps/openmw/mwphysics/skyrimhavok.*`) cached per model by the existing shape manager.
Constraints: clean room (no Havok SDK, no decompiled code, nothing copied from other projects; `docs/research/0144-havok-collision-provenance.md` logs every format fact and how the user's own files confirmed it); hostile-input safe (caps, no index outside an array, no NaN into Jolt); no Jolt shape smaller than its convex radius; threads as `skyrimshape.hpp`; off by default and byte-for-byte the old path when off.
Acceptance criteria:
- [ ] Survey of `bhk` block types, shape trees, layers and motion types over all meshes of the five masters' BSAs (aggregates only), stage a.
- [ ] The Havok-to-game unit scale and the compressed mesh decoding are settled on the user's data (provenance log), not on memory.
- [ ] Reader tests on generated bytes (`apps/components_tests/nifscene/testbhk.cpp`).
- [ ] In game (Bannered Mare, Whiterun exterior): the player stands, stairs walk, barricades and banners that lost collision in task 0140 block again; counts of models by origin; main-thread build time.
- [ ] With the setting off, the Morrowind dump (`tools/worldobjects_check`) and the fixed Balmora frame equal a parent build, and a Skyrim session with the setting off equals the parent's collision.
Out of scope: dynamic bodies and constraints (plan 4.10 to 4.12), ragdoll data, collision layers/filters as Jolt layers (all bodies are one static world shape), MOPP code (the shape under it is used), `bhkNiTriStripsShape`/`bhkMeshShape`/`bhkMultiSphereShape`/`bhkConvexListShape`/`bhkPlaneShape` unless the survey shows they matter.
