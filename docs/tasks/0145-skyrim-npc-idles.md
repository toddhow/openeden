# Task: Skyrim SE NPCs loop the calm standing idle, decoded on a worker (M-S3, idle clips)

Design doc section: `docs/design/skyrim-se-implementation-plan.md` 4.11 and 4.12 (decision D4: our own graph on CreativeMotion plus clips converted from the game's `.hkx`; behaviour graphs are not read). Follow-up of task 0132.
Status: approved under toddhow's blanket "go with your recommendations" (2026-11-11); the coordinator asked for it on 2026-11-12.

Goal: with `[Game] neutral actor idles` on (and `neutral actors`), a Skyrim SE NPC in a neutral session loops the ordinary standing idle `mt_idle` of its sex, decoded once on a worker thread, not the hands-raised unarmed stance of task 0132.

Inherited code touched: none in behaviour. `apps/openmw/mwrender/scene.cpp` `attachNeutralIdle` (the call site of 0132, behind the same setting).

Changes:
- `HavokPack::clipHkxPath(skeletonNif, clipName, sexFolder)`: with a sex folder the clip is `<actor folder>/animations/<male|female>/<clip>.hkx`; a folder containing `/`, `\` or `.` gives an empty path.
- `SkyrimIdle::loadIdleAsync(vfs, skeletonNif, sexFolder, clipName)`: one `std::async` worker per (skeleton, clip), the future shared by every actor (a failed load is a ready null, logged once on the worker). The synchronous `loadIdle` and the old `Controller` constructor stay (tests).
- `SkyrimIdle::Controller(future, boneMap, phaseFraction)`: does nothing until the future is ready (`wait_for(0)`, no block); the first ready frame names the tracks from the actor's bone map (lower-case name to `Anim::Transform`, built at attach from `Anim::Bones::forEach`) and sets the phase to the ref-id hash fraction times the clip duration; afterwards sampling uses scratch sized at that moment, no allocation. The bone map is dropped once resolved. A `skyrimidle.run` load-trace scope times each run (one atomic read when off).
- Clip: `mt_idle` (`SkyrimIdle::sAmbientIdle`), male or female by `ActorAppearance::female`.

Constraints: off by default (the setting exists since 0132, in `tools/testprofile/profile.cfg` and the README). Deterministic: phase from the ref id, no clock or random. Threads: the decode runs on a worker and only reads the VFS (documented thread safe) and writes its own cache under a mutex; `run` on the object's update thread. No root motion; the NPC's capsule and position are not touched.

Acceptance criteria:
- [x] Sex-folder path and bad-folder refusal are tested (red first against a stub, then green).
- [x] The controller waits for the future, resolves by name, skips bones the actor lacks, survives a failed or invalid future (`SkyrimIdleAsync`, 5 tests; written with the code, not run red).
- [x] In game, Bannered Mare NPCs stand in the relaxed idle (arms down, feet on the floor) and the pose changes over seconds.
- [x] With the setting off nothing changes; Morrowind unchanged against a parent build of main (`2a6bc83cb7`).
- Out of scope: other clips, sitting, sleeping, talking, locomotion, creatures, root motion, the behaviour graph, a pelvis correction.
