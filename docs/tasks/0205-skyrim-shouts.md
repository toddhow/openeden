# Task: Skyrim shouts, first slice (M-S7): words, dragon souls, the shout key, Unrelenting Force, the cooldown HUD, the save
Design doc section: `docs/research/0056-skyrim-combat-survey.md` section 8; decision `docs/decisions/0018-skyrim-combat-hooks.md`; tasks 0186 and 0191 (the magic runtime), 0200 (the progression service this one copies for its shape), 0201 (the Lua HUD document pattern), 0198 (the Papyrus natives).
Approval: toddhow asked for "as much Skyrim work as possible overnight" (2026-11-15). Full loop in form (the same hand wrote tests and code; tests first, run red against stubs).
Goal: with `[Game] neutral combat` and `[extension.skyrimse] shouts`, the player knows words, unlocks them with dragon souls, holds a key to shout one, two or three words of the equipped shout, the word's spell is cast through the magic runtime (Unrelenting Force staggers and hurts an NPC), a recovery cooldown starts and is shown on the HUD, and all of it survives a save.
Inherited code touched: none. OpenEden code touched outside the new files, each by a few lines: `sdk/include/openeden/game/combat_rules.hpp` (0.6: one trailing virtual `onPlayerShoutEdge`), `apps/openmw/mwphysics/neutralcombatbridge.*`, `physicssystem.*` and `apps/openmw/mwworld/worldimp.cpp` (the key), `game_packs/skyrimse` `combat.hpp`, `combat_magic.cpp` (a `Cast` flag, two lines in `fireCast`, one call in `updateMagic`), `combat_stats.*` (SHOU, WOOP and two GMSTs), `world_view.*` (three forwards), `papyrus_host.*`/`papyrus_world.*` (three natives and their hooks only), `skyrimse_game_pack.cpp` (wiring), `extension.json`, CMake lists, `files/data`.
Constraints: everything behind `[Game] neutral combat` plus the pack setting `shouts` (off by default); no allocation in a frame once the state is built; main thread only; no wall clock and no random number (the cooldown counts the combat clock).
Out of scope: NPC shouts (the AI never shouts), the real word wall's reading animation, the dragon soul absorption, a shout menu (the equipped shout comes from a test setting), the shout animations (`shoutready`, `shoutstart`: the aimed cast clip `MRh_Release` is used), the shout's own voice sound, a real push (see decision 2), perks that change a shout's cooldown.

## Survey (at `bd2a8093a5`)
- **The magic runtime this reuses.** `game_packs/skyrimse/src/combat_magic.cpp`: `SkyrimCombat::beginCast` (checks magicka, picks the cast clip `MRh_Release` for aimed delivery, the player waits for the time `CombatRequestWriter::clipEventTime(..., SpellFire, ...)` gives), `fireCast` (pays the cost, `reportSpellUse`, then `applySpellEffects` or `launchSpell`), `launchSpell` (the PROJ of the first effect that names one), `resolveSpellShot` (applies the effects to what the bolt hits), `applyOneEffect` (Stagger plays the stagger clip on an NPC, a ValueModifier changes health), `updateMagic` (the per-frame entry). A cast with a spell effect gated by a CTDA is skipped unless `combat test spell conditions` (task 0186).
- **Records.** `decodeSpell` and `decodeMagicEffect` (`perks.cpp`), `Walker::onRecord` and `CombatIndex::add` (`combat_stats.cpp`) collect SPEL and MGEF of every plugin; `SkyrimWorldView::spellByEditorId` forwards them to the combat rules (`world_view.cpp`). Nothing reads SHOU or WOOP yet.
- **The attack control.** `onPlayerAttackEdge` reaches the pack from `PhysicsSystem::updateNeutralActors`-time input (`physicssystem.cpp`, the `mNeutralPlayerState` hook set in `worldimp.cpp` reads `A_Use`); a shout needs a second control. `apps/openmw/mwinput/actions.hpp` has no spare action; `A_CycleSpellRight` (the `=` key, `bindingsmanager.cpp`) is the one that has no meaning in a Skyrim neutral session (its handler `ActionManager::executeAction` cycles the player's Morrowind spell list, which the stub player does not have).
- **Save chunks and bindings.** `progression_service.cpp` (`Chunk`, `declare`), `map.cpp` (`MapChunk`, `MapService::declare`): a `SaveChunkHandler` with `write`/`read`, and a `BindingsService` namespace the Lua scripts `require('core.skyrimse.<name>')`; `builtin.omwscripts` starts a player script only when the pack declares the namespace (`REQUIRES=core.skyrimse.map>=1.0`).
- **The HUD document.** Task 0201 wrote its HUD as Lua on `openeden.ui` (`files/data/openeden/skyrimse/compass.lua`, `scripts/openeden/skyrimse/map_player.lua`), not by editing `hud.cpp`; this task does the same.
- **Papyrus.** `papyrus_host.cpp` `reg("Game", ...)` registers natives; a world effect goes through `PapyrusWorldHooks` (`papyrus_host.hpp`) implemented by `PackWorldHooks` (`papyrus_world.hpp`) with an env of `std::function`s.

## Layouts settled by the data (`SkyrimShoutsRealData`, five masters; Python reading of `Skyrim.esm` agrees)
- **SHOU:** `EDID`, `FULL` (4, a string id), `MDOB` (4, the menu display object, a form id), `DESC` (4), then exactly three `SNAM` of 12 bytes: word (WOOP form id), spell (SPEL form id), recovery time (float, seconds). 117 SHOU in the five masters (Skyrim 75, Dawnguard 24, Dragonborn 18), every one with 3 SNAM (two Dragonborn records have no `FULL`).
- **WOOP:** `EDID`, `FULL` (4, the word's name as a string id), `TNAM` (4, the translation as a string id); 107 records.
- **Unrelenting Force** (`UnrelentingForceShout` 0x13e07): words WordFus, WordRo, WordDah (`WordDragonFire01`... are other shouts'), spells `VoiceUnrelentingForce1/2/3`, recovery 15, 20, 45 seconds. The SPEL's SPIT: cost 2 (`mCost`, **a shout costs no magicka**), type 11 (voice power), cast type 1 fire and forget, delivery 2 aimed. Effects: `VoiceUnrelentingForceEffect01/02/03` (MGEF archetype 33 Stagger, primary value -1, projectile `VoiceUnrelentingForceProjectile`, magnitude 0.75, 1.25, 1.5) and `UnspecifiedDamageFFAimed` (a ValueModifier on health, magnitude 2, 5, 10). **Level 3 is gated by CTDAs**: its second effect has a spell-level condition and its first MGEF carries one, so with the pack's rule "an effect with a condition is skipped" level 3 hurts but does not stagger (decision 3).
- **GMSTs:** `fShoutTime1` 0.2 and `fShoutTime2` 0.9 (seconds).
- **Not in the data:** the dragon soul count (an actor value in game, a Papyrus call), what each word wall teaches (its script calls `Game.TeachWord(word)`), the equipped shout (the player's save).

## Design
1. **`shouts.*` (pure, tests first).** `ShoutRecord`, `WordRecord`, `decodeShout`/`decodeWord`; `ShoutSettings` (the two GMSTs); `ShoutState`: learned words, unlocked words (a word is unlocked by learning it AND spending one dragon soul, or by `forceUnlock` for the script native), souls, the equipped shout, the cooldown (remaining and total) counted in combat-clock seconds, a revision; `wordsUnlockedIn(shout)` (the leading run of unlocked words); `wordsReached(held, available, settings)`; the canonical save chunk (`ShoutChunk`, version 1: counts first, ids ascending, souls, equipped, cooldown; refuses anything that does not fit its size exactly).
2. **Casting (`combat_shout.cpp`).** The press starts counting the hold; each word is reached at `(n-1) x fShoutTime2` seconds held, a release before `fShoutTime1` is a cancel with no cooldown, the last available word fires by itself. The word's spell is cast through `beginShoutCast`: the same aimed clip timing as a player spell, no magicka check and none charged, no skill training, the cooldown starts when the spell goes (the recovery of the word reached). A press while the cooldown runs, with no shout equipped or no word unlocked, is refused with a trace line and nothing happens.
3. **The key.** Contract 0.6: `CombatRules::onPlayerShoutEdge(bool pressed)` (a trailing virtual, default nothing). The core reads the real action `A_CycleSpellRight` (the `=` key, rebindable in the usual way) in the same hook as the attack action and tells the pack on each edge. With the pack setting `shouts test shout every` the pack presses by itself.
4. **Unrelenting Force.** Through the existing effects only: Stagger plays the stagger clip on an NPC, the damage effect hurts it, the bolt is the effect's own PROJ. **No push**: the core has no way for the pack to move an actor (a request writer has clips, rays, sweeps, projectiles and damage; an actor moves only by its own AI path and animation root motion), so stagger and damage only (decision 2).
5. **HUD.** `files/data/openeden/skyrimse/shouthud.lua` (a document on `openeden.ui`: the shout's name, a bar that empties as the cooldown runs down, the seconds) and `scripts/openeden/skyrimse/shouts_player.lua`, started by `REQUIRES=core.skyrimse.shouts>=1.0`. The pack's namespace `skyrimse.shouts` 1.0: Read `ready`, `revision`, `equipped_name`, `cooldown`, `cooldown_total`, `unlocked_count`, `word_count`, `souls`; Mutate `add_souls(n)`.
6. **Natives.** `Game.TeachWord(word)`, `Game.UnlockWord(word)`, `Game.IsWordUnlocked(word)` (a word wall's script) through three new defaulted virtuals of `PapyrusWorldHooks`, `PackWorldHooks` forwarding to the service.
7. **Test settings** (all in `extension.json`, off by default): `shouts` (bool), `shouts test learn` (a list of WOOP editor ids), `shouts test unlock` (a list; each unlocks and spends a soul, souls are granted to pay for it), `shouts test souls` (int), `shouts test shout` (the equipped SHOU editor id), `shouts test shout every` (seconds between automatic presses, 0: the real key only) and `shouts test shout hold` (seconds each automatic press holds).
